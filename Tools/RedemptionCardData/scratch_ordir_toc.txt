Set Abbreviations 
 
When a card appears in a list, the name will be followed by a set (or list of sets) in which cards 
with that name appear. If multiple cards in a set have the same name, there will be some 
identifying information in brackets after the name but before the set(s) to differentiate them. 
These are the set abbreviations:

cards will be identified with the following abbreviations:
